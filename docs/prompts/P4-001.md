## Tasks

### 1. T3 deterministic set → `data/benchmark/t3/`

**Parse**
- Use the P2-003 Amendment Directions.
- Keep those whose text **explicitly** substitutes, deletes or inserts a numbered paragraph of a linked Direction (302 of 333 cite paragraph numbers).
- For each, parse the action, the target clause, the effective date and, for substitutions, the new text.
- Use deterministic rules only.

**Validity check**
- The harvested consolidated Directions may already carry amended text ("Updated as on …").
- For each parsed action, check whether the corpus paragraph matches the old text or the new text. Record `corpus_version: original | amended | unclear`.
- Report the counts.
- **Build items only where the answer follows unambiguously.**

**Items**
- About 60 (paragraph, as-of date) pairs, seeded.
- Balanced before and after the effective date.
- Spread across Directions. At most 5 items per Direction.

**Gold**
- `status` ∈ {`in_force_original`, `amended`, `deleted`};
- `governing_instrument` = the md_id or the amendment item id.

**Spot-check sheet** `data/benchmark/t3/t3_spotcheck_sheet_v1.csv`
- 20 parsed actions, stratified by action type.
- Columns: the amendment text excerpt, the parsed action, target and date, then blank `correct` (`yes` / `no`) and `note`.
- Header note: "Check each parse against the amendment text only. No AI tools."
- Ingest follows the usual rules:
  - accept the file once (sha256 and received-at);
  - validate the vocabulary, the BOM and blanks;
  - `label_source: manual`.
- **Parse precision:**
  - Report it with n = 20 and a Wilson CI.
  - If any parse is `no`, fix the rule and rebuild the set, and report both precisions.
  - **Don't re-sample the sheet after a fix.** Report the fixed rule's effect on the 20 checked rows only.

**Circularity note (state it in the report)**
- Gold comes from the same parser that the temporal filter uses.
- So no "rule-only" system is reported as a T3 result: it would be correct by construction.
- T3 measures whether the **LLM pipeline** uses the date information correctly.

### 2. Pipeline `src/rag/pipeline.py`, plain Python (no LangGraph)

**Input:** `query`, an optional `entity_class`, an optional `as_of` date, and three flags: `class_filter`, `temporal_filter`, `verifier`, all on by default.

**Steps**
1. **Retrieve:** hybrid RRF (P3-001), top 20. The query's own source paragraph is always excluded.
2. **Class filter:** keep paragraphs whose Direction's entity class equals `entity_class`, plus function-heading Directions (the stand-ins included) whose subject family matches.
3. **Temporal filter:**
   - drop paragraphs deleted as of `as_of`;
   - for paragraphs amended as of `as_of`, attach the amendment action, text and effective date;
   - if `as_of` is before an amendment's effective date, mark the paragraph "original in force; amended from <date>".
4. **Answer:** the LLM answers from the top 5 kept paragraphs, citing `[paragraph_id]`, or says it cannot answer. Directions are shown with their title and class.
5. **Verifier:**
   - **NLI model:** `cross-encoder/nli-deberta-v3-xsmall`, pinned to a revision hash. This is RePASs' NLI model, so load it in the main env.
     - Read the label order from the model's `id2label`. Don't assume it.
     - If it can't be pinned, stop.
   - **Supported sentence:** premise = the cited paragraph(s), hypothesis = the answer sentence. The sentence is supported iff the argmax label is entailment.
     - This rule is fixed in config now. There is no threshold tuning.
   - **Retry:** if any sentence is unsupported, retry **once**.
     - The reformulation is deterministic, with no LLM call: re-retrieve with query = original query + the unsupported sentence(s), keep the same filters, and take the top 5.
     - Then make one answer call.
   - **Abstain:** if a sentence is still unsupported, the pipeline returns "cannot answer reliably" plus the evidence paragraphs.

**Logging:** log every step's inputs and outputs per query to `data/rag_runs/` (gitignored), including the call count and cache hits.

### 3. System runs

#### T1 (validated set, 106 items)

**One LLM call per item**
- The prompt gives the source obligation and, **for each compared class**, its evidence block.
- The model returns, per compared class: `judgement` (`same` / `different` / `none` / `unsure`), `matched_paragraph_id` (for `same` / `different`) and a one-sentence `rationale`.
- `applies_to` and the flag are derived with the Guidelines v3 mapping.

**Evidence budget (equal across systems)**
- **Class-aware:** the top 5 paragraphs per compared class, retrieved within that class.
- **Class-blind:** the top 5 × K paragraphs from class-blind hybrid, where K = the number of compared classes.

**Verifier on T1**
- It applies only to `same` / `different` judgements, with the rationale checked against the matched paragraph. A `none` can't be verified by entailment; say so.
- A judgement that is still unsupported after the retry becomes `unsure` (an abstention). The derived flag then follows the mapping.

**Systems**

| System | What it is |
|---|---|
| majority | P3-001 |
| P2-002 candidate labels | dense within-family (P3-001) |
| class-blind LLM | class filter off, no verifier |
| class-aware LLM | class filter on, no verifier |
| **final agentic** | class filter on, verifier on |
| **long-context LLM** | the source paragraph plus the full text of the compared classes' Directions in that subject family, in one prompt |

**Long-context baseline details**
- Cap the input at **150K tokens**. Truncate each class's text proportionally, and record the truncation per item.
- No retrieval, no filters, no verifier.

**Metrics**
- **Main:** 3-way flag Macro-F1 over the gold labels `shared` / `class-specific` / `absent`. A predicted `ambiguous` counts as wrong.
- **Collapsed flag Macro-F1** (`absent` vs the rest), so the numbers compare with P2-002.
- Per-class judgement F1.
- Coverage (the share not abstained).
- The confusion matrix.
- Seeded bootstrap CIs (2,000 resamples).

**If the long-context LLM wins, report it plainly.**

### 4. Ablations
Each ablation is ON vs OFF, with everything else at "final agentic". Report the paired bootstrap differences (seeded, 2,000 resamples) with 95% CIs.

| Ablation | Toggle | Measured on |
|---|---|---|
| A | class filter | T1 3-way and collapsed Macro-F1; T2 nDCG@10 on all three sets |
| B | temporal filter | T3 exact match and supersession F1 |
| C | verifier | T1 Macro-F1 and coverage; on the T4 questions: unsupported-sentence rate, abstention rate and RePASs composite |
