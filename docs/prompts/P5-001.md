**Findings the Results and Discussion must state plainly** (take the numbers from the files):
- **RQ1:**
  - The class filter improves T2 retrieval on all three relevance sets. The gain is partly by construction, because relevance was labelled only for the target-class counterpart. Show `hybrid_minus_source_class` next to it.
  - The class filter has no significant effect on T1 judgement.
- **RQ2:**
  - No LLM system significantly beats the P2-002 candidate labels on collapsed F1, which is the fair comparison. 3-way F1 favours LLMs by design, because P2-002 can't express shared vs class-specific.
  - The class-blind LLM has the highest 3-way F1.
  - Every system is weak on `different` judgements, so class-specific differences are the benchmark's hardest case. This is a contribution, not a failure: it shows what the benchmark catches.
- **Verifier:** it lowers T1 3-way F1 and coverage. Write "changes 3-way flag F1 by −0.068 [CI]" or "lowers it by 0.068". Never "lowers … by −0.068".
- **Long-context:**
  - statistically tied with P2-002, class-blind and class-aware;
  - matches final agentic on 3-way F1;
  - beats final agentic and class-blind + verifier on collapsed F1;
  - weak on `different`.
- **RQ3:**
  - Concatenation gameability reproduces.
  - The adversarial (negated, off-topic) versions do not.
  - Report RePASs's correlation with human `faithful` and with `answers_question`.
  - The exploratory repair is not usable.
  - Ablation C's RePASs change is not significant. The verifier and RePASs share an NLI model, so there is partial self-agreement.
- **T3:**
  - The temporal filter's 1.000 is circular by construction.
  - Without the filter, the model almost always answers "in force, original".
  - The corpus holds only amended text.
