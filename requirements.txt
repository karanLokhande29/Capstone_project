# ---------------------------------------------------------------------------
# Pinning policy
# ---------------------------------------------------------------------------
# Kaggle's base image already ships most of the scientific Python stack at
# versions Kaggle itself chose and tested together. Re-pinning one of those
# packages to whatever happens to be installed on a laptop causes pip to
# downgrade or upgrade it inside the notebook, which can drag its dependencies
# with it and break unrelated preinstalled libraries.
#
# So:
#   * Packages ALREADY IN the Kaggle image  -> listed below as comments only,
#     with a minimum version where the code genuinely needs one. Not installed.
#   * Packages MISSING from the Kaggle image -> listed as real requirements,
#     pinned only as loosely as correctness allows.
#
# Verify the assumptions below in the notebook rather than trusting them; the
# base image changes. `scripts/verify_foundation.py` prints the versions it
# actually found.
#
# ---------------------------------------------------------------------------
# Phase 0 (this branch) needs nothing installed on Kaggle
# ---------------------------------------------------------------------------
# The shared foundation uses only the standard library plus PyYAML, and is
# tested with pytest. Both are in Kaggle's base image, so a Phase 0 notebook
# run requires no pip install at all.
# =============================================================================
